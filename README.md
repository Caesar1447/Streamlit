# Breast Cancer Analytics & Machine Learning Portfolio

An evolving data science and machine learning portfolio demonstrating the development of an academic breast cancer analytics project into an enhanced, end-to-end data engineering and machine learning application.

This repository contains two versions of the project.

## Version 1 — Original Streamlit Analytics Dashboard

The original project provides an interactive dashboard for exploring synthetic breast cancer data, descriptive statistics, data visualization, and introductory machine learning.

**[Launch Version 1](https://app-p8jadzmaencccftcfk7zbk.streamlit.app/)**

**Source code:** `main` branch

## Version 2 — Enhanced Data Engineering & Machine Learning Portfolio

Version 2 extends the original project with:

- Reviewed synthetic data, documented quality checks, and reproducible validation
- Dynamic Excel KPI dashboards
- An independent UCI Wisconsin Diagnostic research benchmark
- Random Forest evaluation and anomaly detection
- FastAPI services, Docker, and structured request monitoring
- Automated testing and GitHub Actions CI/CD
- Documentation covering architecture, model evaluation, and responsible use

**UCI benchmark:** 97.37% held-out accuracy and 92.86% malignant sensitivity on a historical research dataset.

**[Launch Version 2](https://breast-cancer-ai-fde-v2.streamlit.app/)**

**[Explore Version 2 source code and full documentation](https://github.com/Caesar1447/Streamlit/tree/fde-v2)**

## Technology Stack

Python · Streamlit · pandas · scikit-learn · FastAPI · Docker · GitHub Actions · Microsoft Excel

## Important Disclaimer

Both versions are educational and research portfolio demonstrations. The synthetic dataset is not a real patient cohort, and the UCI benchmark results do not establish clinical validity. Neither application is intended for medical diagnosis, screening, treatment decisions, or prediction of an individual's future breast cancer risk.

## Project Evolution

Version 1 demonstrates the initial analytics implementation. Version 2 demonstrates subsequent improvements in data quality, machine learning evaluation, software architecture, reproducibility, testing, and deployment practices.
